# InternetRadioPlayer

Ce dépôt contient les sources pour faire fonctionner un lecteur de radios internet, ainsi que les fichiers 3D pour une boite contenant le board et son écran, la batterie et le haut-parleur.

Le board est un Freenove FNK0104B, basé sur une ESP-S3 avec un écran 2.8" (https://store.freenove.com/products/fnk0104?variant=45040270213318) dont la doc complète est ici : https://github.com/Freenove/Freenove_ESP32_S3_Display. Un HP est inclus dans le kit.

Vouos pouvez utiliser ce type de batterie : https://www.amazon.fr/dp/B0H2YNVYJ4. Attention à choisir une batterie avec un connecteur JST 1.25mm 2Pin.
